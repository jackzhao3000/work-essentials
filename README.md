# work-essentials

给 Jie Zhao 用的个人工作资料库。职业本科艺术设计的日常材料，集中在四件事上：讲座与课程 PPT、学术写作和课题申报、城市更新与工业遗产，以及把这些事交给多个智能体协作完成。这个仓库按这四件事分类，只放值得反复打开的技能说明、导出脚本和资源清单。

第三方代码与文档仍适用其原始许可证。版权归原作者，许可文本见各目录的 `LICENSE`（或 `license`）与 `SOURCE.md`。本仓库是个人策展镜像：根目录和各分类里的导读只负责编目，不改写上游作品的权利。

每一类收了什么、上游地址和快照提交，写在该条目的 `SOURCE.md`。

## 如何更新

1. 打开要更新的那一份 `SOURCE.md`，核对其中的上游 URL 是否仍是规范仓库。地址若已迁移，把新的规范 URL、核对日期和原因写回去。
2. 用浅克隆或稀疏检出，只取 `SOURCE.md` 里写明的路径。技能保持浅层目录；资源清单保持 README 级镜像。
3. 覆盖文件后，更新这份 `SOURCE.md` 的快照提交、上游提交时间、镜像日期，以及本次继续排除的路径。
4. 图标包、音效库、预览大图、`node_modules/`、`__pycache__/` 和本地缓存留在上游或本机。
5. 上游克隆失败时保留目录，在 `SOURCE.md` 写上尝试过的 URL 和失败原因，方便下次接着查。
