# 01 教学与讲座 PPT

两份技能分工不同，讲座准备时可以一起用：先定论证结构，再生成可编辑的 PPTX。

## academic-pptx-skill

学术场合的表达标准。每页标题写成结论句，整套幻灯片读下来是一条论证；结果页一页一个证据，并在图上标出发现；借用的图表带引用，结尾停在结论页，方便提问。适合课程讲座、研讨会、开题和课题汇报。MIT。

- 入口：[`academic-pptx-skill/SKILL.md`](academic-pptx-skill/SKILL.md)
- 论证与引用：[`academic-pptx-skill/content_guidelines.md`](academic-pptx-skill/content_guidelines.md)
- 来源说明：[`academic-pptx-skill/SOURCE.md`](academic-pptx-skill/SOURCE.md)

## ppt-master

Hugo He 的 PPT Master。它把主题或已有文档做成可以在 PowerPoint 里继续改的原生文件：母版、形状、由数据生成的图表和表格。本目录收录技能入口、工作流、参考说明，以及 SVG 与 PPTX 互转、文档转 Markdown 的脚本，并带上教学用得上的风格、版式和图表模板。MIT，版权 Hugo He（2025–2026）。
