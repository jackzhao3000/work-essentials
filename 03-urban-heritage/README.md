# 03 城市更新与工业遗产

三类材料各管一件事：规划数据与技术工具的总清单、一份更短的工具索引，以及城市更新技能里和遗产再利用直接相关的部分。

## APA 技术部资源清单

美国规划协会（APA）技术部维护的建成环境数据与技术资源列表，CC0。城市更新课题需要公开数据、测绘和规划技术入口时，先从这里查。

- 清单：[`urban-and-regional-planning-resources/README.md`](urban-and-regional-planning-resources/README.md)
- 来源说明：[`urban-and-regional-planning-resources/SOURCE.md`](urban-and-regional-planning-resources/SOURCE.md)

## Awesome Urban Planning

durbanitas 的 CC0 列表，覆盖研究报告、开放数据、GIS / CAD / BIM 和设计表达工具。仓库仍可访问，体量小，最后一次上游提交在 2024-10。把它当作 APA 清单旁边的工具索引。

- 清单：[`awesome-urban-planning/readme.md`](awesome-urban-planning/readme.md)
- 来源说明：[`awesome-urban-planning/SOURCE.md`](awesome-urban-planning/SOURCE.md)

来自 Abhinav Bhardwaj 的 Urban Design Skills。整库还有街区、容积率、街道等十多项技能；这里只保留 `urban-regeneration`。其中 [`heritage-and-reuse.md`](urban-regeneration/references/heritage-and-reuse.md) 写遗产登录、保护管理计划、适应性再利用、遗产影响评价（HIA）和保护区新建，对应工业遗产与城市更新教学。MIT。
