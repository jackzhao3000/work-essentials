# 02 学术写作与课题申报

## academic-humanizer

面向论文、答辩回复和基金申请的改写技能（含 NSF Project Summary / Description 与 NIH Specific Aims 的单独层次）。它压缩「近年来」「深入探讨」一类空泛句式，把论断强度收回到证据能支撑的程度，并且不改数字、结果和文献。课题申请书保留愿景表述，因为申请书和论文的语域不同。

作者写明：这是按本人已发表文本校准的编辑辅助，用于披露政策之内的清晰与语气，不用于规避 AI 使用检测。MIT。技能在 Claude Code、Codex、MorphMind 中均可作为 `SKILL.md` 使用。
